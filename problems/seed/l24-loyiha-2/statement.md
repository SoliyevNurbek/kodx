Konsol ilovasi yozing: «Kundalik vazifalar», «Shaxsiy kutubxona» yoki «Baholar jurnali». Ma’lumotlar JSON faylda saqlanadi.

## Talablar
- Kamida 2 ta klass (OOP), meros yoki inkapsulyatsiya bilan
- Funksiyalar va modullarga bo‘lingan kod
- Ma’lumot JSON faylda saqlanadi va qayta yuklanadi
- Xatolar `try/except` bilan boshqariladi
- Ish alohida branch’da, main’ga PR orqali birlashtirilgan

## Topshirish
GitHub repozitoriy havolasini yuboring (`https://github.com/<foydalanuvchi>/<repo>`). Repozitoriyda `README.md` bo‘lsin.

> **Xavfsizlik:** loyihada shaxsiy ma’lumotlar (uy manzili, telefon raqami, parollar, API kalitlar) bo‘lmasin. Maxfiy kalitlar faqat `.env` da, u esa `.gitignore` da.
