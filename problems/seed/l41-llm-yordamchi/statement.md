## Talablar
- API kalit faqat `.env` da, `.env.example` repozitoriyda
- Tizim prompti va javob uzunligi cheklovi
- Xatolar va limitlar qayta ishlangan
- README’da ishlatish namunasi

## Topshirish
GitHub repozitoriy havolasini yuboring (`https://github.com/<foydalanuvchi>/<repo>`). Repozitoriyda `README.md` bo‘lsin.

> **Xavfsizlik:** loyihada shaxsiy ma’lumotlar (uy manzili, telefon raqami, parollar, API kalitlar) bo‘lmasin. Maxfiy kalitlar faqat `.env` da, u esa `.gitignore` da.
